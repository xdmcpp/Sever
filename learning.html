基础入门

C++简介

C++是一种通用的编程语言，由Bjarne Stroustrup于1980年代初在贝尔实验室开发。它是C语言的扩展，添加了面向对象编程的特性，同时保持了C语言的高效性和灵活性。

C++广泛应用于系统软件、游戏开发、嵌入式系统、高性能计算等领域，是最受欢迎的编程语言之一。

C++程序基本结构

一个简单的C++程序通常包含以下部分：

HelloWorld.cpp
#include <iostream> // 使用标准命名空间 using namespace std; // 主函数 int main() { // 输出Hello, World! cout << "Hello, World!" << endl; // 返回0表示程序正常结束 return 0; }

包含头文件

include <iostream> 指令告诉编译器包含标准输入输出库，这是C++程序中常用的库。

命名空间

using namespace std; 语句允许我们直接使用标准库中的函数和对象，而不需要使用 std:: 前缀。

主函数

int main() 是C++程序的入口点，每个C++程序都必须有一个main函数。

输出语句

cout << "Hello, World!" << endl; 是输出语句，用于将文本输出到屏幕上。

返回语句

return 0; 表示程序正常结束，返回值0给操作系统。

编译和运行C++程序

要编译和运行C++程序，你可以使用以下步骤：

使用命令行编译器（如g++）

  1. 编写C++代码并保存为 .cpp 文件
  2. 打开命令行终端
  3. 使用 g++ filename.cpp -o outputname 命令编译程序
  4. 使用 ./outputname 命令运行程序（在Windows上使用 outputname.exe）

或者，你可以直接使用我们的在线编译器来编写、编译和运行C++代码，无需安装任何软件。

long

do-while循环

do-while循环先执行代码块，然后检查条件，至少执行一次：

do_while.cpp
#include <iostream> using namespace std; int main() { // 基本的do-while循环 int i = 1; cout << "计数从1到5: "; do { cout << i << " "; i++; } while (i <= 5); cout << endl; // 计算1到10的和 int sum = 0; int j = 1; do { sum += j; j++; } while (j <= 10); cout << "1到10的和: " << sum << endl; // 菜单选择 int choice; do { cout << "\n菜单:" << endl; cout << "1. 添加" << endl; cout << "2. 删除" << endl; cout << "3. 退出" << endl; cout << "请选择 (1-3): "; cin >> choice; switch (choice) { case 1: cout << "执行添加操作..." << endl; break; case 2: cout << "执行删除操作..." << endl; break; case 3: cout << "谢谢使用，再见！" << endl; break; default: cout << "无效的选择！" << endl; } } while (choice != 3); return 0; }

内联函数

内联函数是一种优化技术，编译器会尝试在调用点展开函数体，而不是进行常规的函数调用，从而减少函数调用的开销：

inline_functions.cpp
#include <iostream> using namespace std; // 内联函数声明 inline int max(int a, int b) { return (a > b) ? a : b; } inline double areaOfCircle(double radius) { const double PI = 3.14159; return PI * radius * radius; } int main() { int x = 10, y = 15; cout << "max(" << x << ", " << y << ") = " << max(x, y) << endl; double radius = 5.0; cout << "半径为" << radius << "的圆的面积: " << areaOfCircle(radius) << endl; return 0; }

访问控制

C++提供了三种访问修饰符来控制类成员的访问权限：

public

公共成员可以在任何地方被访问。

private

私有成员只能在类内部被访问。

protected

保护成员可以在类内部和派生类中被访问。

access_control.cpp
#include <iostream> using namespace std; class MyClass { public: int publicVar; // 公共成员 MyClass() { publicVar = 1; protectedVar = 2; privateVar = 3; } void accessAllMembers() { // 在类内部可以访问所有成员 cout << "publicVar: " << publicVar << endl; cout << "protectedVar: " << protectedVar << endl; cout << "privateVar: " << privateVar << endl; } protected: int protectedVar; // 保护成员 private: int privateVar; // 私有成员 }; class DerivedClass : public MyClass { public: void accessMembers() { // 在派生类中可以访问公共成员和保护成员 cout << "publicVar: " << publicVar << endl; cout << "protectedVar: " << protectedVar << endl; // cout << "privateVar: " << privateVar << endl; // 错误！不能访问私有成员 } }; int main() { MyClass obj; // 在类外部只能访问公共成员 cout << "publicVar: " << obj.publicVar << endl; // cout << "protectedVar: " << obj.protectedVar << endl; // 错误！不能访问保护成员 // cout << "privateVar: " << obj.privateVar << endl; // 错误！不能访问私有成员 // 但可以通过公共方法访问所有成员 obj.accessAllMembers(); DerivedClass derivedObj; derivedObj.accessMembers(); return 0; }

继承

继承是面向对象编程的重要特性，它允许创建一个新类（派生类），继承一个或多个现有类（基类）的属性和方法：

多态是面向对象编程的另一个重要特性，它允许使用基类指针或引用来访问派生类对象，并根据对象的实际类型调用相应的方法：
